# متجر طريق النور للطباعة والدعاية

**Alnoor Store** - منصة تجارة إلكترونية متخصصة في خدمات الطباعة والدعاية والإعلان.

## نظرة عامة

متجر رقمي حديث يقدم خدمات طباعة شاملة بما فيها:
- طباعة الكتب والمذكرات
- شنط دعائية بأنواعها
- خدمات الطباعة الرقمية والخارجية
- هدايا ودروع تذكارية
- بالونات دعائية

## تطوير وصيانة

### إضافة منتج جديد

1. أضف المنتج في `data/products.json`
2. الموقع سيعرضه تلقائياً

### تعديل الأسعار

1. عدّل البيانات في `data/products.json`
2. أعد تحميل الصفحة

### تخصيص الألوان

1. عدّل المتغيرات في `css/variables.css`
2. ستطبق على كل الموقع تلقائياً

### إضافة ميزة جديدة

1. أنشئ وحدة جديدة في `js/`
2. استورده في `js/main.js`
3. استخدم الدوال المساعدة من `js/utils.js`
